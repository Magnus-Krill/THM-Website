Standard Adopted March 2025

Five blocks wide.

Negotiated with The Watchmen, then enforced on every main axis. Solid obsidian, odd width, no exceptions.

Six reasons it stuck:

Cost
Five blocks per unit length is cheaper than six, so the axes reach the border sooner.
Repairable
Harder to wall off than four wide, faster to clear than six when someone does.
Navigation
Wide enough to fly an elytra without clipping a wall, and for two players to pass on foot.
Tooling
Meteor's highway tools handle up to six wide, so five leaves headroom for everyone.
Alignment
Odd widths have a true centre block, which makes joining two crews' work trivial.
Consistency
One width across thousands of blocks. No renegotiating every time a crew changes.
